### 👤 Sobre mí

Soy un desarrollador **Full-Stack y Analista** apasionado por la ingeniería de software y la optimización de procesos. Mi enfoque combina la rigurosidad del análisis de datos con la agilidad del desarrollo moderno para construir productos que no solo funcionan, sino que destacan.

* **Ingeniería Front-End:** Experto en ecosistemas **Next.js** y **React**, creando interfaces ultra-rápidas, tipadas y orientadas al usuario.
* **Arquitectura Back-End & IA:** Especializado en la creación de servicios robustos con **Node.js**, integrando pipelines de **Inteligencia Artificial (Transformers & Embeddings)** para elevar la funcionalidad de las aplicaciones.
* **Gestión de Datos:** Diseño y normalización de bases de datos relacionales complejas, utilizando **Prisma ORM** como puente para una persistencia de datos eficiente y segura.
