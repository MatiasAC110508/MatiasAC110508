Mi trabajo se sitúa en la intersección del desarrollo robusto y la innovación inteligente. No solo construyo interfaces; diseño sistemas que piensan y escalan.

* **Front-End Maestro:** Desarrollo de Single Page Applications (SPAs) y aplicaciones SSR con **Next.js**, priorizando el rendimiento, el SEO y un diseño visual impactante (Tailwind CSS).
* **Back-End & IA:** Implementación de servidores escalables con **Node.js** y **Express**, integrando lógica de **IA (Transformers y Embeddings)** para dotar a las aplicaciones de capacidades de procesamiento de lenguaje natural.
* **Arquitecto de Datos:** Diseño y normalización de bases de datos relacionales críticas (PostgreSQL, MySQL). Experto en el manejo de **Prisma ORM** para una comunicación fluida y segura con el servidor.

### 📂 Proyectos de Impacto

#### 🤖 **Embedding & Transformer Translator**
Un sistema avanzado de traducción y procesamiento semántico que conecta un Front-End en **Next.js** con modelos de **Transformers**. 
* **Innovación:** Uso de **Embeddings** para mejorar la precisión contextual en las respuestas del sistema.
* **Stack:** Next.js, Node.js, AI Models Integration.

#### 🎓 **Lummia Platform**
Plataforma de streaming educativo con un enfoque visual disruptivo y navegación de alta velocidad.
* **Desafío:** Crear una experiencia fluida para el consumo de contenido multimedia.
* **Resultado:** Implementación de una UI llamativa (Neon Style) con una arquitectura de componentes reutilizables y conexión eficiente al Backend.

#### 🏥 **Hospital Vida Sana (Data Architecture)**
Diseño integral de una base de datos relacional para la gestión de servicios médicos críticos.
* **Estructura:** Normalización completa para manejar pacientes, diagnósticos y citas sin redundancia, asegurando la integridad de los datos mediante consultas SQL complejas.
